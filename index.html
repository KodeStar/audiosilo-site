A minute in the demo

  1. 1 Open the Oz series and see the books you don't have as ghost spines.
  2. 2 Open A Christmas Carol's Characters tab: only the people you've met so far. The rest stay hidden.
  3. 3 Press play, then drag the seek bar and watch the whole-book timeline follow.
  4. 4 Set a speed and a sleep timer, then check the time left at your speed.
  5. 5 Drop a bookmark with a label and a note.
  6. 6 Press Cmd+K (Ctrl+K) for quick search and actions.
  7. 7 Scan the QR code to carry on in the iPhone app with the same account.

Get started

Run it tonight.

One container, your books mounted read-only. The image includes the web player and ffmpeg.

Docker 
docker run -d --name audiosilo -p 8080:8080 \
  -v "$PWD/data:/data" \
  -v /srv/audiobooks:/library:ro \
  ghcr.io/kodestar/audiosilo-server:latest

docker logs audiosilo   # the admin password and auth code, shown once

Then open https://your-server:8080/admin, sign in as admin and add /library as your first library. The browser warns about the self-signed certificate the first time; that's expected.
